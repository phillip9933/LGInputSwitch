LG Input Switch **1.2.0** is a full release for Windows x64 and CachyOS/Arch Linux
x86_64. It adds built-in support reports to the modern desktop app on both platforms.

## Downloads

- **Windows:** `LGInputSwitch-1.2.0-Windows-x64.zip` — modern tray/settings app,
  including the new Diagnostics tab, Qt runtime, Microsoft runtime installer and notices.
- **Windows legacy:** `LGInputSwitch-1.2.0-Windows-legacy-x64.zip` — existing Win32
  frontend; diagnostics are available in the modern app only. Run one frontend at a time.
- **Linux:** `lginputswitch-1.2.0-1-x86_64.pkg.tar.zst` — GUI with diagnostics,
  CLI, launcher and linked KDE shortcuts. Debug symbols are a separate optional package.
- Application/Qt sources, PKGBUILD, SOURCE_REVISION and SHA256SUMS are attached.
  Application archives and packages are unsigned.

## Built-in diagnostics

Open **Diagnostics → Create report**, review the result, then choose **Copy report**
or **Save report** to share it with a support request. No separate monitor-control
utility is needed for the initial capability/control information requested by maintainers.

Reports include:

- App/build, OS and Qt versions; selected monitor target and configured input codes.
- The last switching attempt's target, source/input values and driver result.
- Read-only brightness (`0x10`) and current-input (`0x60`) checks.
- Advertised VCP controls, MCCS version and any advertised input values for standard
  Input Source (`0x60`) or manufacturer control `0xF4`.
- Readable names for common standard inputs, such as HDMI 1 and DisplayPort 1.
- GPU/driver information on Windows, or ddcutil version/status on Linux.

The report distinguishes missing lists, empty lists, failed reads and malformed
responses. Serial numbers, raw EDID/capability strings, personal file paths and
custom shortcut/label text are omitted. Reports stay local; nothing is uploaded
automatically. Diagnostics send no input-switching commands and change no settings.

Windows checks use system monitor APIs in a separate process with a timeout;
Linux reads the selected target through the existing ddcutil backend. Shared parsing
and process handling limit response size, nesting and execution time. No new
third-party runtime library is required.

## Install and upgrade

Quit the old app first. Windows: back up config.json, extract the complete modern
ZIP and run `LGInputSwitchDesktop.exe`; retain your configuration beside the new
executable. If required, use the included official `runtime/VC_redist.x64.exe`.
See [Windows setup](https://github.com/phillip9933/LGInputSwitch/blob/1.2.0/docs/windows-release.md).

Linux: install with `sudo pacman -U ./lginputswitch-1.2.0-1-x86_64.pkg.tar.zst`.
Existing per-user settings and Plasma assignments are retained. See
[Linux setup](https://github.com/phillip9933/LGInputSwitch/blob/1.2.0/docs/linux-install.md).

## Verification and limits

Automated tests cover capability parsing, input values/names, privacy filtering,
malformed/oversized replies, failed reads, command selection, report export and
timeouts, using synthetic monitors. Windows/Linux build and package checks run
before publication. No automated test sends commands to a physical monitor.

Advertised capability lists can be incomplete or inaccurate. They do not prove
that LG's alternate switching method works; a sent command still does not confirm
a physical input change. No additional monitor compatibility is claimed, and
reports #4, #5 and #25 remain open for voluntary owner feedback. Windows currently
requires AMD graphics for switching. Intel/NVIDIA backends and macOS remain future work.

Project code is AGPL-3.0-or-later; dependency terms are preserved. Substantial
Codex assistance was used in implementation and verification.
