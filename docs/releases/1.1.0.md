LG Input Switch **1.1.0** is a full numeric-version release for Windows x64 and
CachyOS/Arch Linux x86_64 with KDE Plasma 6. Windows requires AMD graphics; other
GPU vendors and macOS remain future work.

## Downloads

- **Windows:** `LGInputSwitch-1.1.0-Windows-x64.zip` — modern tray/settings app,
  deployed Qt DLLs, Microsoft VC++ runtime installer and license notices.
- **Windows legacy:** `LGInputSwitch-1.1.0-Windows-legacy-x64.zip` — original Win32
  frontend with startup/settings/switching-state maintenance fixes.
- **Linux:** `lginputswitch-1.1.0-1-x86_64.pkg.tar.zst` — GUI, CLI, launcher and
  linked KDE shortcuts; optional debug-symbol package is separate.
- Application source, exact Qt dependency sources, PKGBUILD, SOURCE_REVISION and
  SHA256SUMS are attached. Verify checksums before installing. Archives/packages
  are unsigned.

Windows: extract the complete ZIP into a writable folder and run
`LGInputSwitchDesktop.exe`. If runtime DLLs are missing, run the included official
`runtime/VC_redist.x64.exe`. Quit the old frontend first and back up config.json;
copy it beside the new executable to preserve existing settings. Run one frontend
at a time. See [Windows installation and licenses](https://github.com/phillip9933/LGInputSwitch/blob/1.1.0/docs/windows-release.md).

Linux: install the package with `sudo pacman -U ./lginputswitch-1.1.0-1-x86_64.pkg.tar.zst`
and open LG Input Switch from the menu. See [Linux installation](https://github.com/phillip9933/LGInputSwitch/blob/1.1.0/docs/linux-install.md).

## Changes

- Shared modern GUI/tray with system, light and dark themes and responsive
  background discovery/switching.
- Configurable enabled input mappings/order, direct/cycle shortcuts and a
  previous-input action that toggles accepted selections from the current session.
- KDE Plasma application shortcut catalogue, editable in either the app or Plasma.
- Optional native Windows/Linux sign-in startup.
- Windows maintenance: preserve custom codes/config, validate malformed values,
  report shortcut/ADL failures and keep cycle position on rejected commands.
- New AMD session/packet implementation using documented APIs; inherited AMD CLI
  sources are removed. Driver loading is restricted to the Windows system directory.
- Complete Windows runtime/source/notice bundles and a version-checked publishing
  workflow. Tags and build versions use numbers only; this is not a prerelease.
- New project revisions use AGPL-3.0-or-later; third-party terms and earlier MIT
  releases retain their own licenses.

## Validation and known limits

CI builds both Windows frontends and Linux variants, tests the Windows backend
against fake DLLs, verifies exact DDC packet/target/error handling and startup
registration, and launches the packaged GUI without Qt SDK paths. Automated tests
never send monitor commands. The maintainer verified Linux hardware switching,
tray/GUI and linked Plasma shortcuts on CachyOS/KDE Wayland with an LG UltraGear.

Physical Windows AMD switching, real sign-in, fresh-account upgrades and DPI/theme
transitions remain unverified. Reports #4/#5 are not claimed fixed. The LG F4/source-50
profile and default input codes vary by monitor; select a known target/profile.
Only one monitor is actively selected. Bus numbering may change on reconnect and
previous-input history is session-only. Intel/NVIDIA GPU combinations, other Linux
desktops and macOS are not validated by this release.

Substantial Codex AI assistance was used in implementation and verification.
