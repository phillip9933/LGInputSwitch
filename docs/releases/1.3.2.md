LG Input Switch **1.3.2** keeps the existing cross-platform GUI and monitor
switching, with simpler downloads and built-in update controls.

## Downloads

- **Windows:** `LGInputSwitch-1.3.2-Windows-x64.exe` — one portable executable.
  Qt, its platform/TLS plugins and the C++ runtime are linked in. No setup program,
  DLL folder or separate runtime installer is needed. Keep it in a writable folder.
- **CachyOS/Arch:** `lginputswitch-1.3.2-1-x86_64.pkg.tar.zst` — the native package.
- **SHA256SUMS** — checksums for those two downloads.
- GitHub’s automatic source-code ZIP/tar.gz downloads provide the application
  source and build scripts. No legacy Windows or auxiliary source/debug packages
  are uploaded as release assets.

## Upgrade

Quit the old app and back up settings. Windows: put the new executable in your
existing app folder alongside config.json and desktop-profiles.json, keeping its
filename stable on later upgrades. Save settings once if startup is enabled so
Windows uses the new executable path. Older Qt DLL/runtime folders are not required
by this portable build. Linux: install the native package with pacman as usual.
Neither upgrade changes configured monitor mappings.

This is the first updater-capable release, so it must be installed manually.
Future compatible releases can be checked, downloaded and installed from
**Preferences → Application updates**. Checks are daily by default; downloads and
installation require a click. Progress, cancellation, reminders and restart
notifications are included. Windows keeps a previous executable for recovery;
Linux uses pacman and its OS authorization prompt.

## Source, licenses and verification

The Windows executable contains license notices and exact source/rebuild links.
Export them with `LGInputSwitch-1.3.2-Windows-x64.exe --licenses notices.txt`.
Qt 6.8.3 source: [qtbase archive](https://download.qt.io/archive/qt/6.8/6.8.3/submodules/qtbase-everywhere-src-6.8.3.tar.xz),
SHA256 `56001b905601bb9023d399f3ba780d7fa940f3e4861e496a7c490331f49e0b80`.
[The tagged build recipe](https://github.com/phillip9933/LGInputSwitch/blob/1.3.2/packaging/windows/qt-sources.json)
and [rebuild instructions](https://github.com/phillip9933/LGInputSwitch/blob/1.3.2/docs/windows-release.md)
allow rebuilding/relinking with modified Qt. Project code remains AGPL-3.0-or-later;
Qt and other components retain their own terms.

Update downloads use GitHub HTTPS metadata and matching SHA256SUMS, not an
independent publisher signature. [Update behavior and recovery](https://github.com/phillip9933/LGInputSwitch/blob/1.3.2/docs/updates.md)
describes the trust model and installation limits. Executables remain unsigned.

Windows/Linux CI covers the GUI, backends, packaging, update policy, tampering and
native Windows self-replacement/restart in temporary folders. The portable EXE is
tested alone with SDK paths removed. No physical monitor commands are sent by the
checks. Real Windows monitor/sign-in testing remains limited. Windows switching
still requires AMD graphics; Intel/NVIDIA Windows backends and macOS remain future
work. Substantial Codex assistance was used in implementation and verification.
