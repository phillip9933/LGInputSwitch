LG Input Switch **1.3.0** is a full release for Windows x64 and CachyOS/Arch Linux
x86_64. It adds multi-monitor profiles, grouped switching, standard DDC/CI input
switching, automatic input setup and a simpler desktop layout.

## What's new

- **Monitor profiles:** create named tabs with independent actions and shortcuts.
  Assign one or several monitors to a profile; each action selects an input for
  every member, so one shortcut can switch a complete desk setup.
- **Standard monitor inputs:** select standard DDC/CI Input Source (0x60) for
  compatible Dell and other monitors, alongside LG's alternate F4 method. Groups
  can mix methods. Windows switching still requires AMD graphics.
- **Automatic input setup:** read each monitor's own advertised inputs when it is
  added, connected, refreshed or loaded at startup. Dell's vendor USB-C value is
  recognized. LG uses advertised F4 values or retains known alternate codes for
  advertised ports. Missing or incomplete lists retain the previous mapping;
  custom mappings can opt out. Save settings once to apply detected changes.
- **Cleaner interface:** Profiles, Preferences, Advanced and Diagnostics are
  separate top-level pages. Monitor management and action editing expand when
  needed. Pages scroll in smaller windows; status and Save remain accessible.
  The Add Monitor dialog is larger with wrapping text.
- **Per-profile control:** cycle/previous/direct shortcuts, tray submenus,
  per-monitor results and failed-only retries. KDE assignments remain linked
  with Plasma's shortcut manager. Existing input IDs and shortcuts are retained
  when their input remains available; removed-input actions stay disabled for review.
- **Targeting and diagnostics:** re-detect before switching and resolve saved
  identities. Ambiguous connections require explicit selection. Reports describe
  profile members, mappings and results; report content remains local until shared.

Grouped commands are sent to members in sequence; they cannot guarantee precisely
simultaneous changes or roll back a monitor that already switched. Previous input
tracks accepted app actions in the current session, not the initial physical input.
An accepted command is not proof of a physical input change.

## Downloads and upgrade

- **Windows modern:** `LGInputSwitch-1.3.0-Windows-x64.zip` includes the profile GUI,
  tray, Qt runtime, Microsoft runtime installer and notices.
- **Windows legacy:** `LGInputSwitch-1.3.0-Windows-legacy-x64.zip` retains the original
  single-monitor Win32 frontend. Run only one frontend at a time.
- **CachyOS/Arch:** `lginputswitch-1.3.0-1-x86_64.pkg.tar.zst` includes the GUI, CLI,
  launcher and linked KDE shortcuts. Debug symbols are optional. Rolling-release
  Qt dependencies may require a current system.
- Application/Qt sources, PKGBUILD, SOURCE_REVISION and SHA256SUMS are attached.
  Application archives and packages are unsigned.

Quit the old app and back up settings before upgrading. Windows: preserve
config.json and desktop-profiles.json beside the new executable. Linux: preserve
`~/.config/LGInputSwitch/LGInputSwitchDesktop.conf`, then install with
`sudo pacman -U ./lginputswitch-1.3.0-1-x86_64.pkg.tar.zst`.

Existing single-monitor settings import into a Main profile. Review connections,
detected inputs and actions, then save. Original legacy settings are retained.
The profile workspace uses schema v3 and imports v2; older profile builds reject
the newer data. Restore the backed-up settings when rolling back. Grouped actions
need an input choice for every member because the app cannot infer which ports
connect to the same computer.

See [Windows setup](https://github.com/phillip9933/LGInputSwitch/blob/1.3.0/docs/windows-release.md),
[Linux setup](https://github.com/phillip9933/LGInputSwitch/blob/1.3.0/docs/linux-install.md)
and [profile setup](https://github.com/phillip9933/LGInputSwitch/blob/1.3.0/docs/desktop-ui.md#monitor-profiles).

## Verification and limits

Automated tests cover migration, persistence, monitor routing, mixed command
methods, partial failure/retry, history isolation, shortcut preservation,
automatic capability setup, failed reads, custom overrides, compact layouts and
diagnostics. Windows/Linux builds, native Arch/KDE packaging and extracted Windows
ZIP launch checks run before publication. Tests use synthetic targets and send
no physical input-switching commands.

The maintainer tested the Linux profile/layout update on CachyOS/KDE with an LG
UltraGear and Dell S2722QC; read-only queries returned four LG inputs and three
Dell inputs. Physical Windows AMD switching remains unverified. Advertised lists
may be inaccurate or incomplete, and monitor-specific reports remain dependent
on voluntary owner feedback. Windows capability reads use a unique EDID match;
ambiguous native mappings retain existing inputs. This release does not add
Windows Intel/NVIDIA backends or macOS support.

Project code is AGPL-3.0-or-later; dependency terms and corresponding source are
preserved. Substantial Codex assistance was used in implementation and verification.
