**2.0.0 Beta 1** is the first public test of a larger update to LG Input Switch. The biggest changes are broader Windows GPU support and a reworked desktop interface. If you prefer the stable version, [1.3.4 is still available](https://github.com/phillip9933/LGInputSwitch/releases/tag/1.3.4).

### Added

- **NVIDIA on Windows.** On a directly connected display that LG Input Switch can match to an NVIDIA output, it can now send LG’s alternate input command through the NVIDIA driver. This brings a switching method previously available on AMD to compatible NVIDIA setups.
- **Intel on Windows.** The app identifies Intel-driven displays and uses Windows’ standard DDC/CI interface for input switching, brightness and capability reports. An LG monitor that requires the alternate command still needs a supported AMD or NVIDIA connection. The GPU driving the display, the monitor itself and any dock all matter.
- **Per-monitor brightness** in the workspace and tray quick panel. Linux continues to use ddcutil on supported connections.

### Changed

- Input Profiles and Monitors now use tabs. You can edit assignments, reorder actions, and customize a monitor’s inputs in place. A tray click opens quick controls. A double-click opens the workspace.
- Linux updates can be downloaded and verified in the app, then installed with the system package manager.

### Fixed

- Canceling action edits and saving monitor assignments leaves saved monitor switches available. Add and Remove work on automatically detected input lists, and removing a mapped input identifies the affected actions before saving.

### Build information

Download the portable Windows x64 EXE or the x86_64 package for CachyOS and Arch Linux. Back up your settings before testing. Stable installations skip this beta during automatic update checks. The [Qt 6.12.0 source archive](https://download.qt.io/archive/qt/6.12/6.12.0/submodules/qtbase-everywhere-src-6.12.0.tar.xz) is available for rebuilding the portable EXE. The [Windows build recipe](https://github.com/phillip9933/LGInputSwitch/blob/2.0.0-beta.1/packaging/windows/qt-sources.json) identifies the exact Qt source used in the executable.

If you find yourself hunting for a control or clicking through more steps than you expected, please tell me what you were trying to do. Intel and NVIDIA hardware reports are especially welcome, including setups that work. For a switching problem, include your monitor model, GPU, connection or dock, and the report from **Settings → Diagnostics** after reviewing it.
