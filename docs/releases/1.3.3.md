LG Input Switch **1.3.3** adds Thunderbolt input setup for the **LG UltraFine
40U990A-W** on Windows and Linux ([#33](https://github.com/phillip9933/LGInputSwitch/issues/33)).

## What changed

- A detected 40U990A-W gains a separate **Thunderbolt** input using `0xD2` with
  LG alternate switching (`0xF4`). USB-C remains `0xD1`; other models and standard
  DDC/CI mappings are unchanged.
- Automatic setup recognizes the model from live EDID, ddcutil discovery or
  capabilities. If its input list is unavailable/incomplete, Thunderbolt is added
  while existing inputs are kept. Single-monitor profiles gain a Thunderbolt
  action without a shortcut assigned. Existing custom labels/shortcuts and manual
  input mode are preserved.
- For an existing automatic setup, use **Refresh**, review the inputs and click
  **Save settings**. If the monitor reports only a generic model name, add a
  **Thunderbolt** input with `0xD2` manually in **Edit monitor & inputs**. The LG
  source address remains configurable (normally `0x50`).

The reporter confirmed manual `0xD2` switching on this monitor. Automated checks
use synthetic monitors; the new automatic setup still needs confirmation on the
reporter's hardware. This does not add support for other Thunderbolt models.

## Downloads and upgrade

- **Windows:** `LGInputSwitch-1.3.3-Windows-x64.exe` — one portable executable;
  no installer, DLL folder or separate runtime setup. Windows switching requires
  AMD graphics.
- **CachyOS/Arch:** `lginputswitch-1.3.3-1-x86_64.pkg.tar.zst`.
- **SHA256SUMS** — checksums for both downloads. GitHub supplies the source-code
  ZIP/tar.gz archives automatically; no legacy or auxiliary assets are uploaded.

From 1.3.2, use **Preferences → Application updates** to download and install this
release. For a manual Windows upgrade, quit the app and replace the executable in
its existing writable folder, keeping its filename and settings files. Linux
users can install the native package with pacman. Review/save automatic input
setup separately after upgrading.
