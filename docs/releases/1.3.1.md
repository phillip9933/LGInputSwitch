LG Input Switch **1.3.1** is a full maintenance release for Windows x64 and
CachyOS/Arch Linux x86_64.

## Windows startup fix

With **Launch when I sign in** enabled, the modern app now starts directly in
the system tray. It uses the existing background-launch option without adding
another checkbox. Shortcuts initialize while the window is hidden, and the app
can be opened from its tray icon. Normal manual launches retain their existing
behavior; without a system tray, the window opens instead.

This addresses [#30](https://github.com/phillip9933/LGInputSwitch/issues/30).
Input switching, monitor profiles and Linux startup behavior are unchanged.

## Upgrade

Quit the old app and back up your settings before upgrading.

- **Windows:** extract `LGInputSwitch-1.3.1-Windows-x64.zip`, preserving config.json
  and desktop-profiles.json beside the new executable. Open **Preferences** and
  click **Save settings** once with **Launch when I sign in** checked. This
  refreshes an existing startup entry with the background argument; subsequent
  sign-ins start in the tray. The legacy Win32 alternative remains a separate ZIP.
- **CachyOS/Arch:** install `lginputswitch-1.3.1-1-x86_64.pkg.tar.zst`. This package
  rebuild carries the same monitor-switching features as 1.3.0. Debug symbols are
  optional. Current rolling-release Qt dependencies may require a system update.

See [Windows setup](https://github.com/phillip9933/LGInputSwitch/blob/1.3.1/docs/windows-release.md)
and [Linux setup](https://github.com/phillip9933/LGInputSwitch/blob/1.3.1/docs/linux-install.md).
Application/Qt sources, PKGBUILD, SOURCE_REVISION and SHA256SUMS are attached.
Application archives and packages are unsigned.

## Verification and limits

Windows tests check the quoted startup executable path, the background argument,
repeated registration, command updates and removal in an isolated CI account.
Windows/Linux build and packaging checks, including an extracted Windows ZIP
launch check, run before publication. A real Windows sign-in session was not
tested on the maintainer's Linux laptop. No physical input-switching commands
were sent during verification.

Windows switching still requires AMD graphics. Existing monitor/GPU compatibility
limits remain; Intel/NVIDIA Windows backends and macOS are future work.
Project code is AGPL-3.0-or-later; dependency terms and corresponding source are
preserved. Substantial Codex assistance was used in implementation and verification.
